# Справка по новым инструментам и гайд на проекте parchomenko.pulse

Версия: после `0.9.0-rc6` (ветка `feature/qt-ui`, ноябрь 2026). Все проверки пройдены
автоматически (130 юнит-тестов, сквозной сценарий в окне, снимки интерфейса).

## Что добавлено (кратко)

| Инструмент | Где | Что делает |
|---|---|---|
| **Элемент** | «Контроль» → «Объекты» | Плоскость/сфера/цилиндр/окружность по щелчку; σ, отклонение формы; известный Ø; ветвь «Элементы» в дереве |
| **Боксы отсечения** | «Контроль» → «Сечения» → «Бокс» / «Кликом» | Изоляция комнаты: видны точки только внутри включённых боксов; несколько боксов объединяются; сечение режет поверх |
| **Планы** | «Контроль» → «Планы» | Сечение → именованный план; активация — камера вдоль плоскости (орто); замеры привязываются к плану |
| **Чертёж сечения** | «Результат» → «Документы» | По срезу (план/разрез/развёртка) или **проекцией элементов** (участок с уклоном); SVG/DXF/PNG 1:1 |
| **Замеры: снап, правка, H, undo** | «Контроль» → «Замеры» | Привязка к вершинам/центрам (B), правка числом (✎), H-отметка, Ctrl+Z, разрез/объединение площадей (✂/⧉), код слоя |
| **Экспорт замеров** | кнопки в панели замеров | CSV (Excel) и 3D-DXF (метры, слои IZM_* — совместимы с Оттиском) |
| **Горизонт** | «Совмещение» → «Горизонт и план» | «Кликом» — по полу с диалогом (галочка «нулевая отметка»); «Транспортир» — вручную кольцами |
| **Виды** | камера в шапке → «Сохранить вид» | Именованные позиции камеры, двойной клик в дереве — полёт |

## Гайд: участок с уклоном (parchomenko.pulse)

Сценарий: план участка с забором и фасадом здания, разрез комнаты, замеры, чертёж.
Проект открывается как обычно (`Открыть` → `parchomenko.pulse`); дождитесь окончания
анализа (внизу «анализ N/N»).

### Шаг 1. Выровнять горизонт по площадке

Участок с уклоном: автоприведение «По горизонту» может ошибаться.

1. Вкладка **«Совмещение»** → группа **«Горизонт и план»** → **«Кликом»**.
2. Щёлкните по горизонтальной площадке (пол, отмостка) — появится диалог: наклон,
   который будет снят, и галочка **«Выставить нулевую отметку ±0.000 по этой плоскости»**
   — поставьте её.
3. **«Выровнять»**. Проверка: сетка 1 м (глаз «Сетка 1 м» в дереве) параллельна площадке,
   замер «Отметка» на площадке покажет ≈ ±0.000.

Если подходящей плоскости под кликом нет — подгоните её инструментом «Элемент»
(тип «плоскость») и выберите в дереве у элемента **«Выровнять горизонт по элементу»**.
Доворот «вручную» — **«Транспортир»**: кольца вокруг сцены, тянуть мышью
(Shift — в 10 раз точнее, Esc — выйти).

### Шаг 2. Изолировать фасад здания (бокс)

1. Вкладка **«Контроль»** → **«Сечения»** → **«Бокс»** — бокс по габариту видимых
   сканов (или **«Кликом»** — центр по щелчку, размер как у последнего).
2. Размер — двумя способами: **объёмные стрелки-ручки на гранях** — по одной на
   грань, из её центра наружу, цвета по осям (X красная, Y зелёная, Z синяя);
   появляются при выборе бокса в дереве; тяга двигает только эту грань —
   противоположная на месте (Shift — шаг 5 см); или
   **числами** — «Контроль» → «Боксы»: имя («Фасад»), центр, размер, поворот
   (появляются при инструменте «Сечение» / «Нулевой уровень» / «Замеры»).
3. В дереве ветвь **«Боксы отсечения»**: глаз выключает/включает бокс. Всё вне бокса
   скрыто — точки не удаляются (в отличие от чистки).

Для работы с двумя комнатами/участками сразу — включите два бокса (объединение).

### Шаг 3. Замеры: фасад и забор

1. **«Замеры» → «Расстояние»**: щёлкните две точки. Прицел сам подхватывает
   **вершины замеров, центры и углы подогнанных элементов** раньше облака
   (синий прицел — элемент, жёлтый — замер; B — выключить привязку; клик мимо
   целей ничего не ставит).
2. У строки замера: **✎** — название («Сторона забора С»), примечание, **координаты
   вершин числом** (3 знака = мм), **код слоя** («забор», «фасад» — попадёт в CSV и DXF);
   **H** — отметка первой точки второй строкой подписи; ✂/⧉ — разрезать/объединить
   площади; Ctrl+Z отменяет.
3. Сферы/цилиндры (столбы забора, бочки): «Элемент» → тип «сфера»/«цилиндр»;
   известный диаметр держится при подгонке.

### Шаг 4. План участка проекцией (главное для уклона)

Один срез периметр забора на склоне не ловит — используйте **проекцию элементов**:

1. Подогните плоскости по щелчку: каждый прямой сегмент забора и стены фасада
   (наклон сегментов не мешает).
2. В дереве в ветви **«Элементы»** оставьте глаз включённым только у нужных.
3. **«Результат» → «Чертёж сечения»** → Источник: **«проекция элементов»** →
   Плоскость листа: **«горизонт.»** → **«Построить»**. В результат: контуры, длина,
   список пропущенных (параллельные листу плоскости — «пятном» — пропускаются).
4. Развёртка фасада: тот же источник, плоскость листа — **«по элементу»**, выбрать
   плоскость фасада. Сам фасад и параллельные ему плоскости пропускаются (штатно —
   список в результате). Проверено на parchomenko: развёртка по «Плоскость 15»
   (353.7 м²) — 9 контуров, 39.7 м, перпендикулярные стены легли в лист.
5. **«Предпросмотр»** → **«Сохранить SVG/DXF/PNG…»** (1:1, мм; DXF-слои:
   contour/grid/openings/text).

### Шаг 5. План этажа срезом (комната «Электрощитовая»)

1. **«Контроль» → «Сечения» → «Срез»**, основа «гориз.», отметка 1.200 — на экране
   полоса (план этажа). Вместе с боксом комнаты — план только её.
2. **«Контроль» → «Планы» → «Сохранить сечение»** — имя «1 этаж». План появится
   в дереве; глаз — активировать (камера сама встанет сверху в ортопроекции),
   новые замеры привяжутся к плану; «Завершить план» — обзор.
3. **DXF плана** — в меню строки плана (замеры плана + контур среза слоем CONTOUR).

### Шаг 6. Сдать результаты

- **Экспорт CSV…** — все замеры по вершинам (Excel);
- **Экспорт DXF…** — замеры в 3D (метры, слои `IZM_<код>_<тип>`);
- DXF плана (шаг 5), SVG/DXF/PNG чертежа (шаг 4).

### Имена сканов и панели

- **Переименовать** (сканы, группы, элементы, боксы, планы, виды): правая кнопка
  → «Переименовать» — имя правится **прямо в строке дерева** (Enter — применить,
  Esc — отменить; у групп также поле «Тип»). Отображаемое имя скана хранится в
  проекте; связи и файлы не меняются (в тултипе — исходное короткое имя).
- **Скрыть панели**: клик по кнопкам-«ушкам» на границах 3D-вида (слева — дерево,
  справа — панель инструмента, снизу — пары/циклы/качество), меню **«Вид»** или
  клавиши **F2 / F3 / F4**. Стрелка ушка (одного размера во всех трёх) показывает,
  куда панель двинется при клике: у открытой — к краю окна, у закрытой — обратно
  в сторону 3D-вида. Состояние запоминается в настройках.

### Проверка качества стыковки (если сомнения)

«Контроль» → «Качество совмещения» (порог 3 см), «Циклы графа», вкладка «Связи».
Ориентиры: RMS плоскости ±15 мм; толщина общих поверхностей до 2–3 см — норма.

## Что проверено автоматически (сводка по этой работе)

- **130 юнит-тестов** (было 89 до работы): подгонки fits (7), чертежи (11), боксы (10),
  замеры/снап/экспорт/планы (19), сеанс (элементы, undo, уровни, виды), + прежние.
- **Сквозной сценарий в окне** (фактический прогон, лог): бокс → 6 GPU-плоскостей;
  срез + бокс → сечение на GPU, бокс на CPU (лимит OpenGL 6 плоскостей — найдено
  и исправлено в этой проверке); план → орто + вид сверху; замер 4.233 м с именем,
  кодом «1», H-отметкой; элемент «Плоскость 1» σ 17 мм, 9907 т.; чертёж 6 контуров /
  9.8 м / 19 проёмов; экспорт 4 файлов (CSV 320 Б, DXF 16 КБ, план DXF 31 КБ, SVG 5 КБ).
- **Снимки всех вкладок ленты и панелей** — текст помещается, кнопки на месте
  (найдено и исправлено: обрезанная подпись «Бокс кликом» → «Кликом»).
- Исправлено по итогам прохода: **композиция бокс+сечение** (OpenGL-лимит 6
  клипплоскостей: при активном сечении боксы рисуются CPU-маской, лёгкая
  синхронизация при движении среза), подпись кнопки.
