# Справка по новым инструментам и гайд на проекте parchomenko.pulse

Версия: **1.0.0** (ветка `feature/qt-ui`, ноябрь 2026). Все проверки пройдены
автоматически (133 юнит-теста, сквозной сценарий в окне, снимки интерфейса).

## Что добавлено (кратко)

| Инструмент | Где | Что делает |
|---|---|---|
| **Элемент** | «Контроль» → «Объекты» | Плоскость/сфера/цилиндр/окружность по щелчку; σ, отклонение формы; известный Ø; ветвь «Элементы» в дереве |
| **Боксы отсечения** | «Контроль» → «Сечения» → «Бокс» / «Кликом» | Изоляция комнаты: видны точки только внутри включённых боксов; несколько боксов объединяются; сечение режет поверх |
| **Планы** | «Контроль» → «Планы» | Сечение → именованный план; активация — камера вдоль плоскости (орто); замеры привязываются к плану |
| **Чертёж сечения** | «Результат» → «Документы» | По срезу (план/разрез/развёртка) или **проекцией элементов** (участок с уклоном); SVG/DXF/PNG 1:1 |
| **Замеры: снап, правка, H, undo** | «Контроль» → «Замеры» | Привязка к вершинам/центрам (B), правка числом (✎), H-отметка, Ctrl+Z, разрез/объединение площадей (✂/⧉), код слоя |
| **Экспорт замеров** | кнопки в панели замеров | CSV (Excel) и 3D-DXF (метры, слои IZM_* — совместимы с Оттиском) |
| **Фото** | «Результат» → «Фото» | Привязка снимка к облаку (пары точек или совмещение поверхности) и окраска точек пикселями фото; слой «Фото (окраска)», экспорт PLY/E57 с цветами |
| **Горизонт** | «Совмещение» → «Горизонт и план» | «Кликом» — по полу с диалогом (галочка «нулевая отметка»); «Транспортир» — вручную кольцами |
| **Виды** | камера в шапке → «Сохранить вид» | Именованные позиции камеры, двойной клик в дереве — полёт |

## Гайд: участок с уклоном (parchomenko.pulse)

Сценарий: план участка с забором и фасадом здания, разрез комнаты, замеры, чертёж.
Проект открывается как обычно (`Открыть` → `parchomenko.pulse`); дождитесь окончания
анализа (внизу «анализ N/N»).

### Шаг 1. Выровнять горизонт по площадке

Участок с уклоном: автоприведение «По горизонту» может ошибаться.

1. Вкладка **«Совмещение»** → группа **«Горизонт и план»** → **«Кликом»**.
2. Щёлкните по горизонтальной площадке (пол, отмостка) — появится диалог: наклон,
   который будет снят, и галочка **«Выставить нулевую отметку ±0.000 по этой плоскости»**
   — поставьте её.
3. **«Выровнять»**. Проверка: сетка 1 м (глаз «Сетка 1 м» в дереве) параллельна площадке,
   замер «Отметка» на площадке покажет ≈ ±0.000.

Если подходящей плоскости под кликом нет — подгоните её инструментом «Элемент»
(тип «плоскость») и выберите в дереве у элемента **«Выровнять горизонт по элементу»**.
Доворот «вручную» — **«Транспортир»**: кольца вокруг сцены, тянуть мышью
(Shift — в 10 раз точнее, Esc — выйти).

### Шаг 2. Изолировать фасад здания (бокс)

1. Вкладка **«Контроль»** → **«Сечения»** → **«Бокс»** — бокс по габариту видимых
   сканов (или **«Кликом»** — центр по щелчку, размер как у последнего).
2. Размер — двумя способами: **объёмные стрелки-ручки на гранях** — по одной на
   грань, из её центра наружу, цвета по осям (X красная, Y зелёная, Z синяя);
   появляются при выборе бокса в дереве; тяга двигает только эту грань —
   противоположная на месте (Shift — шаг 5 см); или
   **числами** — «Контроль» → «Боксы»: имя («Фасад»), центр, размер, поворот
   (появляются при инструменте «Сечение» / «Нулевой уровень» / «Замеры»).
3. В дереве ветвь **«Боксы отсечения»**: глаз выключает/включает бокс. Всё вне бокса
   скрыто — точки не удаляются (в отличие от чистки).

Для работы с двумя комнатами/участками сразу — включите два бокса (объединение).

### Шаг 3. Замеры: фасад и забор

1. **«Замеры» → «Расстояние»**: щёлкните две точки. Прицел сам подхватывает
   **вершины замеров, центры и углы подогнанных элементов** раньше облака
   (синий прицел — элемент, жёлтый — замер; B — выключить привязку; клик мимо
   целей ничего не ставит).
2. У строки замера: **✎** — название («Сторона забора С»), примечание, **координаты
   вершин числом** (3 знака = мм), **код слоя** («забор», «фасад» — попадёт в CSV и DXF);
   **H** — отметка первой точки второй строкой подписи; ✂/⧉ — разрезать/объединить
   площади; Ctrl+Z отменяет.
3. Сферы/цилиндры (столбы забора, бочки): «Элемент» → тип «сфера»/«цилиндр»;
   известный диаметр держится при подгонке.

### Шаг 4. План участка проекцией (главное для уклона)

Один срез периметр забора на склоне не ловит — используйте **проекцию элементов**:

1. Подогните плоскости по щелчку: каждый прямой сегмент забора и стены фасада
   (наклон сегментов не мешает).
2. В дереве в ветви **«Элементы»** оставьте глаз включённым только у нужных.
3. **«Результат» → «Чертёж сечения»** → Источник: **«проекция элементов»** →
   Плоскость листа: **«горизонт.»** → **«Построить»**. В результат: контуры, длина,
   список пропущенных (параллельные листу плоскости — «пятном» — пропускаются).
4. Развёртка фасада: тот же источник, плоскость листа — **«по элементу»**, выбрать
   плоскость фасада. Сам фасад и параллельные ему плоскости пропускаются (штатно —
   список в результате). Проверено на parchomenko: развёртка по «Плоскость 15»
   (353.7 м²) — 9 контуров, 39.7 м, перпендикулярные стены легли в лист.
5. **«Предпросмотр»** → **«Сохранить SVG/DXF/PNG…»** (1:1, мм; DXF-слои:
   contour/grid/openings/text).

### Шаг 5. План этажа срезом (комната «Электрощитовая»)

1. **«Контроль» → «Сечения» → «Срез»**, основа «гориз.», отметка 1.200 — на экране
   полоса (план этажа). Вместе с боксом комнаты — план только её.
2. **«Контроль» → «Планы» → «Сохранить сечение»** — имя «1 этаж». План появится
   в дереве; глаз — активировать (камера сама встанет сверху в ортопроекции),
   новые замеры привяжутся к плану; «Завершить план» — обзор.
3. **DXF плана** — в меню строки плана (замеры плана + контур среза слоем CONTOUR).

### Шаг 6. Сдать результаты

- **Экспорт CSV…** — все замеры по вершинам (Excel);
- **Экспорт DXF…** — замеры в 3D (метры, слои `IZM_<код>_<тип>`);
- DXF плана (шаг 5), SVG/DXF/PNG чертежа (шаг 4).

## Фото: окраска облака по снимкам

Облако серое (канала интенсивности в данных нет); снимки с телефона (статичные,
со штатива или с рук) раскрашивают точки своими пикселями — получается
фотореалистичная модель. Фото может покрывать часть поверхности: непокрытые точки
остаются в обычном цвете скана; на одном фото можно совместить несколько поверхностей
(внешний и внутренний угол здания).

### Цвета фото и точность

- **Каждому фото — свой цвет** (жёлтый, голубой, зелёный…): точки пар в 3D и крестики
  на снимке одного цвета; активное фото — ярко и крупно, остальные приглушены. Цветная
  метка стоит в строке фото в панели.
- **Точность.** Рамка поверхности даёт грубую позу; точность определяют:
  1. **пары по углам проёмов** (окна, двери) — клик по фото примагничивается к углу
     краёв с суб-пиксельной точностью (чекбокс «магнит OpenCV»), в 3D — по тому же углу;
     4–6 пар по окнам дают точность в единицы пикселей;
  2. **«Уточнить по краям»** — при наличии позы уточняет **позу** по контурам всех
     выровненных поверхностей (не ручки поодиночке); один проход, ограниченное окно,
     принимается только улучшение; повторные нажатия сходятся.
- В плотном облаке окна **не являются пустотами** (стекло и рамы дают точки), поэтому
  автоуточнение по «дырам» на таких фасадах не работает — только края оболочки и пары.

### Шаг 1. Добавить снимки

«Результат» → **«Фото»** → «Добавить…» (можно несколько сразу). Файл копируется в
папку `photos/` рядом с проектом — проект переносим целиком. Фокусное (эквивалент
35 мм) берётся из EXIF, если он есть; иначе впишите вручную (26–28 мм — основная
камера телефона, 14–16 — широкий угол) **или** «Подобрать по парам» после привязки
(нужно ≥4 некопланарных пары).

> Фокусное в пикселях считается по диагонали кадра (`f = f35 · hypot(w,h) / 43.27`):
> для портретных снимков это важно — по ширине фокусное занизилось бы на треть.

### Шаг 2а. Привязка парами точек

1. «Добавить точку» — клик по характерному месту на фото в окне снимка (угол окна,
   проём, угол здания), затем — по той же точке в 3D-виде. Нужно **не меньше 4 пар**;
   лучше 6–8 на **разных** плоскостях (стена + земля/соседний фасад). Кликать можно по
   точкам **любого размещённого скана** — опорный нужен лишь как система координат;
   окраска тоже красит все размещённые сканы, не только опорный.
2. «Привязать» — поза камеры из PnP; в панели появится σ (пиксельная невязка).
   Больше 20–30 px — что-то не так: проверьте фокусное, аккуратность кликов и что
   пары на разных поверхностях (все пары на одной плоскости решаются гомографией;
   сторона плоскости тогда выбирается по облаку).
3. Пары видны в 3D (маркеры своего цвета) и на фото (крестия) — **точки можно
   двигать**: на снимке потяните крестик мышью (клик без протяжки — новая точка),
   в 3D потяните маркер по облаку. После правки нажмите «Привязать» — поза
   пересчитается. Цвет маркеров совпадает с цветом фото в панели: активное фото
   ярко и крупно, остальные приглушены.

### Шаг 2б. Совмещение поверхности (без пар)

1. В «Поверхность (плоскость)» выберите элемент-плоскость, подогнанный инструментом
   «Элемент» (фасад, стена).
2. «Совместить по фото» — на снимке ляжет слой поверхности: её **реальные точки**
   (фактура; проёмы видны пустотами) и 8 ручек. При выборе поверхности в списке
   режим включается сам и окно снимка открывается — слой виден сразу.
   > Слой и рамка строятся по **плотному ядру** инлайнеров (перцентили 2–98 %):
   > у «фасада В» полный охват 33.6×14.8 м включает тонкие крылья, и рамка по полному
   > охвату растягивалась вдвое против видимой стены. Крылья видны хвостами точек.
3. Тяните ручки:
   - **середина ребра** — масштаб и положение: едет всё ребро (оба угла на то же Δ);
   - **угол** — перспектива: угол и две ближайшие середины на Δ/2;
   - одним **щелчком** ручка переносится в точку щелчка (без протаскивания);
   - ручки тянутся и **за пределы кадра** (фото покрывает часть поверхности);
   - лупа ×3 у курсора — для точного прицеливания.
   > Ручки не перекрещивайте: порядок (TL, TR, BR, BL) задаёт соответствие углов.
4. «Применить позу» — поза камеры из гомографии ручек (порядок ручек однозначен;
   перебора симметрий нет — на почти-квадратной стене он выбирал повёрнутый
   зеркальный вариант). Из двух кандидатов (±масштаб) берётся тот, при котором
   инлайнеры поверхности видны в кадре: у зеркального все точки уходят за камеру.
5. «Уточнить по краям» (явная кнопка, ограниченный проход ±28 экранных px): ручки
   слегка подтягиваются к краям фото (Canny + дистанционная трансформа). Магнит
   отключается чекбоксом; **автоматических сдвигов при отпускании нет** — ручка
   остаётся там, куда её поставили.

Несколько поверхностей на одном фото: каждая выровненная поверхность запоминается в
фото — выберите следующую в списке и совместите так же.

### Панорамы 360°

Сшитые панорамы (MADV360, Insta360 и т.п., кадр 2:1 equirectangular) распознаются
при добавлении **автоматически** — по кадру 2:1 или метке XMP GPano в файле
(переписывание мессенджерами не мешает). В панели у такой съёмки появляется бейдж
«360°», а секции «Фокусное» и «Совмещение поверхности» исчезают: у панорамы нет
ни фокусного, ни «за камерой» — поза это позиция + поворот.

Привязка — только парами точек (шаг 2а), но проще:

- **«камера у сканера»** (чекбокс со списком сканов, включён по умолчанию): панораму
  держали рядом со штативом — выберите в списке, у **какого размещённого скана** стоял
  штатив (по умолчанию опорный); центр камеры берётся позицией сканера этого скана, и
  хватает **3 пар** по разным стенам. Самый быстрый и надёжный путь.
- чекбокс выключен — поза решается полностью (6 степеней свободы), нужно **4+ пары**;
  желательно не в один ряд и не у пола/потолка (полюса панорамы растянуты).

Окраска — как у обычных фото (шаг 3): точка красится пикселем по своему лучу, из
нескольких съёмок побеждает ближайшая камера — панорамы и обычные фото можно
смешивать в одном проекте. Ограничение: если в надир панорамы попал сам фотограф,
пол под камерой окрашится «цветом тела» — такие зоны прикройте панорамой с другой
позиции или обычным фото.

### Шаг 3. Окраска и экспорт

- Кнопка **«Окрасить облака»** или слой **«Фото (окраска)»** в дереве. Точка
  красится пикселем ближайшей камеры, которая её видит; z-буфер не даёт красить точки
  за стенами; пиксели внутри выровненной поверхности окрашивают только точки этой
  плоскости (±3σ).
- Непокрытые фото точки на экране остаются цветом скана из палитры.
- **Экспорт**: «Результат» → «Экспорт склейки» → формат PLY/E57/PCD и галочка
  «цвета по фото» (в экспорте непокрытые точки — **чёрные**: видно покрытие,
  например в CloudCompare).
- Глаз в ветви «Фото» дерева — участвует ли снимок в окраске (неудачный можно
  отключить, не удаляя); двойной клик — окно снимка, меню — переименовать/удалить.

### Подводные камни (из живой отладки)

- **Фокусное неверно** → поверхность «уезжает» по глубине при «Применить»; при
  неверном фокусном и парах σ будет большой. Сравните окраску при 14/20/26 мм.
- Все пары на одной плоскости → поза по гомографии: точна на этой плоскости, но
  соседняя геометрия и глубина зависят от фокусного.
- «Точки за камерой» при привязке — зеркальное решение от вырожденных пар; добавьте
  пару на другой поверхности.
- Слои режима совмещения восстанавливаются после перерисовки окна фото — пары и
  ручки не пропадают при открытии окна.

### Имена сканов и панели

- **Переименовать** (сканы, группы, элементы, боксы, планы, виды): правая кнопка
  → «Переименовать» — имя правится **прямо в строке дерева** (Enter — применить,
  Esc — отменить; у групп также поле «Тип»). Отображаемое имя скана хранится в
  проекте; связи и файлы не меняются (в тултипе — исходное короткое имя).
- **Скрыть панели**: клик по кнопкам-«ушкам» на границах 3D-вида (слева — дерево,
  справа — панель инструмента, снизу — пары/циклы/качество), меню **«Вид»** или
  клавиши **F2 / F3 / F4**. Стрелка ушка (одного размера во всех трёх) показывает,
  куда панель двинется при клике: у открытой — к краю окна, у закрытой — обратно
  в сторону 3D-вида. Состояние запоминается в настройках.

### Проверка качества стыковки (если сомнения)

«Контроль» → «Качество совмещения» (порог 3 см), «Циклы графа», вкладка «Связи».
Ориентиры: RMS плоскости ±15 мм; толщина общих поверхностей до 2–3 см — норма.

## Что проверено автоматически (сводка по этой работе)

- **133 юнит-теста** (было 89 до работы): подгонки fits (7), чертежи (11), боксы (10),
  замеры/снап/экспорт/планы (19), сеанс (элементы, undo, уровни, виды), + прежние.
- **Сквозной сценарий в окне** (фактический прогон, лог): бокс → 6 GPU-плоскостей;
  срез + бокс → сечение на GPU, бокс на CPU (лимит OpenGL 6 плоскостей — найдено

## Исправлено перед релизом 1.0.0

- **Удаление бокса отсечения** (`Ctrl+Delete` в дереве или «Удалить бокс») убирало
  сам бокс из фильтра, но в сцене оставались его каркас и ручки-стрелки. Теперь при
  перерисовке сравнивается множество нарисованных боксов: удалённые снимаются вместе
  с группой объектов (`cbox:*`, `cboxg:*`), а если боксов не осталось — облака
  перестают обрезаться CPU-маской. Проверка — шаг `cbox` в `tests/qt_smoke.py`.
- **Правая панель при старте** скрывала стек инструментов, но не свою обёртку — на
  месте панели оставалась пустая плашка. Инициализация панелей теперь использует
  единое соответствие «панель → скрываемый виджет» и явное состояние, а не `isVisible()`
  до первого `show()`.
- **Кнопки-«ушки» панелей**: нативная стрелка Qt масштабировалась под размер кнопки,
  из-за чего у боковых ушек стрелка была 4×6 px, а у нижнего — 27×16 px. Шеврон
  рисуется сам (`Theme.chevron`, оверсамплинг ×3 под HiDPI) и во всех трёх ушках
  имеет один размер; направление показывает, куда панель двинется при клике.
- **Прокрутка дерева**: после перестройки (`rebuild`) восстановленное значение
  прокрутки обрезалось старой максимальной высотой — перед установкой вызывается
  `executeDelayedItemsLayout()` (было 462→102, стало 462→432).
