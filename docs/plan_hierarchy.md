# План: иерархия сканов (здание → блок → этаж → комната)

Статус: реализовано 2026-10-02 (`scan_tree.py`, `Session.tree`, дерево на вкладке «Проект», стыковка по дереву, экспорт ветки). Выравнивание горизонта и плана по ветке — не сделано.

## Зачем

Сейчас сканы проекта — плоский список. Когда объектов станет много (несколько помещений, этажей, зданий), нужно:
- группировать сканы в дерево произвольной глубины: здания, блоки, этажи, комнаты, «снаружи» и т.п.;
- скрывать и показывать целую ветку или отдельный скан;
- выбирать опорный скан прямо в дереве.

## Модель данных (`project.json`)

```json
"tree": {
  "id": "root", "name": "Проект", "kind": "проект", "visible": true,
  "children": [
    {"id": "g1", "name": "Здание А", "kind": "здание", "visible": true, "children": [
      {"id": "g2", "name": "1 этаж", "kind": "этаж", "children": [
        {"id": "g3", "name": "Комната 101", "kind": "комната",
         "children": [{"scan": "static_20260922_231157.e57"}, {"scan": "static_20260922_231252.e57"}]}
      ]},
      {"id": "g4", "name": "Фасады", "kind": "снаружи",
       "children": [{"scan": "static_20260922_234415.e57"}]}
    ]}
  ]
}
```

- Узел-группа: `id`, `name`, `kind` (любая строка, предлагаются: здание, блок, этаж, комната, снаружи, прочее), `visible`, `children`.
- Лист — ссылка на скан из `scans`. Каждый скан входит ровно в одну группу.
- **Совместимость.** Старый проект без `tree` открывается так, будто все сканы лежат в корне. Позы, рёбра и чистка не меняются: дерево только организует сканы и не влияет на геометрию.

## Логика (`scan_session.py`, тестируется без окна)

- `Tree`: добавить, переименовать или удалить группу (сканы удалённой группы переходят к родителю); переместить скан или группу в другую группу с защитой от циклов; обход ветки.
- **Видимость.** Скан виден, если видим он сам и все его предки. Галочка группы скрывает всю ветку, а состояние галочек внутри неё сохраняется.
- **Опорный скан.** Выбор листа → `Session.set_frame(id)`, затем пересчёт поз по графу (уже есть).
- **Стыковка по уровням** (следующий шаг, ускоряет перебор пар):
  - автостыковка сначала внутри каждой листовой группы (комната);
  - затем между соседними группами уровня выше, по одному представителю на группу или по выбранным парам групп.
  - При N сканах это сильно меньше N(N−1)/2 пар: сейчас 45 пар считаются 8–15 минут.
- **Операции над веткой:** экспорт только ветки; выравнивание горизонта и плана по стенам только по сканам ветки; «показать только ветку».

## Интерфейс (`scan_gui.py`)

Вкладка «Проект»: вместо плоского списка сканов — `gui.TreeView` с `CheckableTextTreeCell` (галочка — видимость, текст — имя и состояние: «опорный» / «размещён» / «НЕ размещён», цвет скана).

| Кнопка | Действие |
|---|---|
| Новая группа | дочерняя группа в выбранной; имя и тип — в диалоге |
| Переименовать | имя и тип выбранной группы |
| В группу... | переместить выбранный скан или группу (список групп; перетаскивания мышью в Open3D TreeView нет) |
| Удалить группу | сканы переходят к родителю |
| Сделать опорным | для выбранного скана |
| Только эта ветка | показать выбранную ветку, скрыть остальное |
| Экспорт ветки | склейка только сканов ветки |
