# Pulse Scan 1.0.0

**Скачать:**
- `PulseScan-v1.0.0-macOS-arm64.dmg` — открыть и перетащить в «Программы»;
- `PulseScan-v1.0.0-Windows-x64.zip` — распаковать и запустить `Pulse Scan.exe`.

Первый запуск неподписанной программы — см. руководство, раздел 1. Руководство лежит внутри пакета (папка «Руководство») и открывается в программе клавишей F1.

## 1.0.0 (2026-11-06) — что нового после 0.9.0-rc6

Первый релиз без приставки «rc»: все функции на месте, проверки пройдены. Главное — инструменты выпуска: элементы, отсечение, чертежи и планы.

- **Элементы по щелчку** — «Контроль» → «Элемент»: щелчок по облаку подгоняет **плоскость, сферу, цилиндр или окружность** (есть «авто»), с точностью подгонки σ и отклонением формы; «известный диаметр» держит радиус при подгонке. Элементы в ветви **«Элементы»** дерева, движутся вместе со своими сканами и попадают в чертежи.
- **Боксы отсечения** — «Контроль» → «Сечения» → **«Бокс»** (по габариту видимых сканов) или **«Кликом»**: видны точки **только внутри** включённых боксов, всё снаружи скрыто (точки не удаляются, в отличие от чистки). Несколько боксов **объединяются**; сечение режет поверх бокса. Размер — ручками на гранях (по одной на грань, цвета по осям; Shift — шаг 5 см) или числом в панели «Боксы отсечения».
- **Планы** — «Контроль» → «Планы» → **«Сохранить сечение»**: сечение становится именованным планом. Глаз в дереве активирует план: камера встаёт вдоль плоскости в ортопроекции, новые замеры **привязываются к плану**, на сцене остаются только его замеры. Из меню строки плана — **экспорт DXF** (замеры плана + контур среза слоем CONTOUR).
- **Чертёж сечения** — «Результат» → «Чертёж сечения»: по включённому **срезу** (горизонтальный — план этажа, вертикальный — разрез, по стене — развёртка фасада) или **проекцией элементов** — для участка с уклоном, где один срез не ловит периметр. Контуры осевыми линиями, проёмы, сетка 1 м, штамп, масштаб 1:1; экспорт **SVG / DXF / PNG**.
- **Замеры стали точными и редактируемыми**: привязка к вершинам замеров и центрам элементов (**B**, синий прицел — элемент, жёлтый — замер); правка вершин **числом** через ✎ (3 знака = мм); **код слоя** и имя — попадают в экспорт; **H** — отметка второй строкой подписи; ✂ / ⧉ — **разрезать и объединять площади**; **Ctrl+Z** отменяет действие с замерами.
- **Экспорт замеров** — **CSV** (по вершинам, для Excel) и **3D-DXF** (метры, слои `IZM_<код>_<тип>` — совместимо с «Оттиском»).
- **Выравнивание горизонта кликом** — «Стыковка» → «Кликом»: щелчок по полу или площадке, диалог со снимаемым наклоном и галочкой **«нулевая отметка ±0.000 по этой плоскости»**; для участка с уклоном, где автомат по всем плоскостям ошибается. Плюс **«Транспортир»** — наклон кольцами вручную (Shift — в 10 раз точнее).
- **Сохранённые виды** — кнопка в шапке 3D-вида «Сохранить вид»: именованная позиция камеры в ветви **«Виды»**; двойной щелчок — полёт к виду.
- **Переименование** прямо в дереве — сканы, группы, элементы, боксы, планы, виды (Enter — применить, Esc — отменить). Отображаемое имя скана хранится в проекте, файлы и связи не меняются.
- **Скрытие панелей («ушки»)** — кнопки на границах 3D-вида: слева дерево, справа правая панель, снизу пары/циклы/качество; то же в меню **«Вид»** и по **F2 / F3 / F4**. Стрелка ушка показывает, куда панель двинется при клике; состояние запоминается.
- **Исправлено:** удаление бокса отсечения убирало и его каркас с ручками из вида; при старте правая панель теперь скрыта целиком, а не пустой плашкой; у всех трёх ушек один размер стрелки; дерево не отбрасывается к началу при восстановлении прокрутки.

Подробности — в руководстве пользователя (разделы про элементы, боксы, планы и чертежи).

## Изменения относительно rc5

- **Элементы по щелчку** («Контроль» → «Элемент»): плоскость, сфера, цилиндр, окружность или «авто» — кликом по облаку, с σ (точность поверхности) и отклонением формы; известный диаметр держится при подгонке. Список в панели, ветвь «Элементы» в дереве с глазом и меню; хранятся в проекте, движутся со сканами.
- **Чертежи сечений** («Результат» → «Чертёж сечения»): по срезу — план этажа / разрез / развёртка фасада с отметками проёмов; **проекцией элементов** — для участка с уклоном (периметр забора и фасады на одном листе; плоскость листа — горизонтальная или по элементу). Осевые линии, линии и дуги 1:1 (мм), сетка 1 м, штамп; предпросмотр и экспорт SVG / DXF / PNG, синий контур 0,5 мм.
- **Горизонт кликом** — щелчок по полу: найденная плоскость, диалог подтверждения, галочка «нулевая отметка ±0.000 по этой плоскости». Для участков с уклоном, где автоприведение ошибается. **Транспортир** — ручной наклон проекта кольцами вокруг сцены (Shift — точнее, Esc — выйти). «Выровнять горизонт по элементу» — в меню плоскости в дереве.
- **Привязка замеров (B)** — прицел подхватывает вершины замеров и центры/вершины подогнанных элементов раньше облака; клик мимо целей ничего не ставит.
- **Ctrl+Z в режиме замеров** — отмена действий с замерами (стек до 10), не мешает отмене чистки вне режима.
- Исправлено: щелчок глаза в дереве у нижних строк сбрасывал прокрутку в начало.

Подробности — «Что нового в 0.9.0-rc6» в пакете (папка «Руководство», PDF) и в репозитории (docs/manual/CHANGES-0.9.0-rc6.md).

# Pulse Scan 0.9.0-rc5 — релиз-кандидат

Первая сборка Pulse Scan в виде готового приложения для **macOS (Apple Silicon)** и **Windows (x64)**: Python и другие программы ставить не нужно.

**Скачать:**
- `PulseScan-v0.9.0-rc5-macOS-arm64.dmg` — открыть и перетащить в «Программы»;
- `PulseScan-v0.9.0-rc5-Windows-x64.zip` — распаковать и запустить `Pulse Scan.exe`.

Первый запуск неподписанной программы — см. руководство, раздел 1. Руководство лежит внутри пакета (папка «Руководство») и открывается в программе клавишей F1.

## Изменения относительно rc4

- **Панели инструментов.** Инструмент без параметров срабатывает сразу; инструмент с параметрами открывает справа свою панель: область, параметры, оценка времени, «Выполнить» с прогрессом и «Остановить», результат. Shift + щелчок по кнопке — запуск с прошлыми настройками.
- **Запекание групп.** Группа с зафиксированными внутренними позами стыкуется с остальными как одно облако. Виртуально и обратимо: «Распечь» возвращает сканы.
- **Настройки отображения** скана и группы: цвет (свой, по высоте, по дальности), размер точек, обрезка по дальности и высоте — только на экране или и в расчётах и экспорте.
- **Импорт проекта в проект** — новой группой со сканами, связями, чисткой и кешем анализа.
- **«Принять позу» больше не сдвигает скан:** противоречащие связи отключаются, ручные связи весят больше автоматических.
- **Автостыковка выделенных сканов** из дерева проекта. При перезапуске ваше «принять» / «отклонить» сохраняется, только если пара пересчиталась в ту же позу.
- **Стыковка далёких сканов** (парковка, улица): гипотеза от текущей позы, правило малого перекрытия; слабые пары, ломающие циклы, отключаются.
- **Вкладка «Связи»:** от какого скана каждый скан получил позу, расхождения итога со всеми связями, причины «не размещён».
- **Подсказки в таблице «Пары»:** что значат оценка, нарушения, отрыв, RMSE и метод, почему пара принята или отвергнута.
- **«Открыть недавние»** — стрелка у кнопки «Открыть» и пункт меню.
- Руководство: новые разделы, исправлены снимки куба навигации и ленты.

## Изменения относительно rc3

- **Прогресс автостыковки:** в строке состояния — номер пары («пара 123 из 780») и оценка оставшегося времени по скорости этого компьютера. Раньше на большом числе сканов программа выглядела зависшей.
- **Остановка автостыковки:** кнопка «Остановить» в строке состояния или Esc. Посчитанные пары сохраняются, повторный запуск продолжает с места.

## Изменения относительно rc2

- **Руководство в PDF** — `Руководство/PulseScan-manual.pdf` внутри пакета (оглавление со ссылками, для печати).

## Изменения относительно rc1

- **Windows: пути с кириллицей.** Сканы, проекты и экспорт в папках вроде «Рабочий стол», «Документы» или при кириллическом имени пользователя теперь читаются и пишутся. Раньше облако читалось пустым, а экспорт не создавал файл.
- **Windows: построение поверхности.** Расчёт сетки падал при удалении временного файла.

## Что умеет

- **Импорт:** прямо со сканера по сети (`pulse.local`, с докачкой), из папки с записями (bag), готовые облака (E57, PLY, PCD, LAS). Реконструкция записи с калибровкой лидара — из записи или по дате.
- **Проект:** файл `.pulse` с кешем анализа (открывается за секунды); дерево групп с перетаскиванием, группировкой и удалением; упаковка для передачи (zip / папка).
- **Стыковка:**
  - автоматическая — по плоскостям и ICP, по дереву, внутри групп, группы между собой;
  - таблица пар и циклов с ручным принятием и отклонением;
  - ручная — по парам объектов, автоподгонка после грубой стыковки, опорная точка с транспортирами и вводом углов;
  - кандидаты позы; выравнивание горизонта и плана.
- **Контроль:** подсветка мест плохого совмещения с порогом и списком мест; срез и отсечение плоскостью (по осям, по стене, с доворотом); **боксы отсечения** — изоляция комнаты/участка с ручками на гранях; нулевой уровень; элементы — плоскость, сфера, цилиндр, окружность по щелчку; замеры — расстояние, отметка, до плоскости, ломаная / площадь; привязка к вершинам и центрам (B), правка числом (✎), отметка (H), разрез/объединение площадей (✂/⧉), код слоя, отмена (Ctrl+Z); планы — именованные планы из сечения с привязкой замеров; экспорт замеров CSV и DXF.
- **Чистка:** зеркальные отражения (авто), движущиеся объекты (между сканами и по полуоборотам), рамка; всё с отменой.
- **Результат:** экспорт склейки и веток в E57 / PLY / PCD; экспериментальная поверхность (Пуассон, ball pivoting) с экспортом в OBJ / PLY / STL; **чертёж сечения** — план / разрез / развёртка по срезу и проекцией элементов (для участков с уклоном); SVG / DXF / PNG.
- **Интерфейс:** лента по этапам работы, светлая и тёмная темы, куб навигации с видами по осям, полёт, перспектива и ортогональная проекция; **ушки панелей** — скрыть дерево, панель инструмента, нижнюю панель (F2–F4); сохранённые виды; переименование прямо в дереве.

## Известные ограничения

- Программа не подписана сертификатами Apple / Microsoft: при первом запуске система показывает предупреждение (см. руководство, раздел 1).
- macOS — только Apple Silicon (M1 и новее).
- Сетки поверхности не сохраняются в проекте (только экспортом).
- Замеры и сечения не следуют за выравниванием горизонта или плана, сделанным после них.
- На активном сечении боксы отсечения рисуются маской на процессоре: при очень больших боксах это заметно по скорости вращения вида.
