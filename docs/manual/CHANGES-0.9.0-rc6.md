# Pulse Scan — что нового в 0.9.0-rc6

Версия программы: **0.9.0-rc6** (релиз-кандидат) · ноябрь 2026

Что появилось или изменилось по сравнению с версией 0.9.0-rc5.

Главное:

1. **элементы по щелчку** — плоскость, сфера, цилиндр, окружность подгоняются кликом по облаку, с точностью подгонки (σ) и отклонением формы; элементы видны в дереве и попадают в чертежи;
2. **чертежи сечений** — план / разрез / развёртка по срезу и **проекция элементов** для участка с уклоном; экспорт SVG / DXF / PNG в масштабе 1:1;
3. **выравнивание горизонта** — кликом по полу (с галочкой «нулевой уровень по этой плоскости») или вручную, транспортиром;
4. **замеры точнее** — привязка к вершинам замеров и центрам подогнанных элементов (клавиша B), отмена — Ctrl+Z.

## Элементы по щелчку

Инструмент «Элемент» (вкладка «Контроль», группа «Объекты»): щелчок по поверхности облака подгоняет к ней геометрический элемент — **плоскость, сферу, цилиндр, окружность** или «авто» (тип определяется по виду поверхности под щелчком). Клик с перетаскиванием по-прежнему вращает вид.

У каждого элемента считаются:

- **σ** — среднеквадратичное отклонение точек от подогнанной поверхности (точность поверхности в этом месте);
- **отклонение формы** — размах остатков (плоскостность, сферичность, цилиндричность);
- размер: площадь плоскости, диаметр сферы/окружности, диаметр и длина цилиндра.

Опция «известный диаметр» держит радиус при подгонке — для калибровочного шара, трубы известного сечения: подгоняется только положение.

Элементы перечислены в панели инструмента (переименование — карандаш, удаление — крестик) и в **ветви «Элементы»** дерева проекта. Глаз у элемента — видимость; правая кнопка: показать/скрыть, переименовать, удалить, **«Выровнять горизонт по элементу»** (у плоскостей). Элементы хранятся в проекте и движутся вместе со своими сканами.

## Чертежи сечений

Инструмент «Чертёж сечения» (вкладка «Результат», группа «Документы») строит чертёж по включённому срезу или проекцией элементов:

- **по срезу** — горизонтальный срез даёт план этажа, вертикальный — разрез, срез по плоскости стены — развёртку фасада. Отмечаются проёмы (двери/окна), которые пересекает плоскость среза;
- **проекция элементов** — точки видимых элементов (ветвь «Элементы» в дереве) переносятся на плоскость листа ортогонально, без среза. Для участка с уклоном, где одну плоскость среза не поймать: периметр забора и фасады здания на одном листе. Плоскость листа — горизонтальная (план участка) или по плоскости одного из элементов (развёртка вдоль неё). Плоскости, параллельные листу, пропускаются (проектируются «пятном») — список пропущенных в результате.

Контуры — осевые линии поверхностей с допуском, дуги и линии в истинном масштабе 1:1 (мм), сетка 1 м, штамп с датой и параметрами. Синий контур 0,5 мм. **Предпросмотр** в окне; экспорт **SVG**, **DXF** (слои contour/grid/openings/text; читается CAD), **PNG**.

## Горизонт и нулевой уровень

Вкладка «Совмещение», группа «Горизонт и план» — два новых способа выровнять горизонт:

- **«Кликом»** — щелчок по горизонтальной поверхности (пол коридора, площадка) берёт найденную плоскость и показывает диалог подтверждения: наклон, который будет снят, и **галочка «выставить нулевую отметку (±0.000) по этой плоскости»**. Позы сканов друг относительно друга не меняются. Способ для участков с уклоном, где автоприведение по всем плоскостям ошибается;
- **«Транспортир»** — кольца вокруг центра сцены: тяните мышью — проект наклоняется на лету (Shift — в 10 раз точнее, предел ±15°, Esc — выйти).

«Выровнять горизонт по элементу» в меню плоскости в дереве — тот же диалог по подогнанной плоскости.

## Замеры: привязка и отмена

- **Привязка (клавиша B, переключатель в панели замеров).** Прицел подхватывает центры и вершины подогнанных элементов, вершины и середины уже поставленных замеров — раньше, чем точки облака. Подсвеченная цель (синяя — элемент, жёлтая — замер) ставится точно; клик мимо целей ничего не ставит. Облако по-прежнему подхватывается, если целей рядом нет.
- **Ctrl+Z в режиме замеров** отменяет последнее действие с замерами (стек до 10): лишний замер, случайную очистку. Вне режима замеров Ctrl+Z, как и прежде, отменяет ручную чистку.

## Прочее

- Элементы и все новые данные хранятся в проекте `.pulse`; старые проекты открываются как раньше.
- Слои «Элементы» и ветвь дерева работают с фильтром поиска по дереву.
- Нулевой уровень, заданный «кликом по плоскости», подписан в панели «Контроль» как «по плоскости (выравнивание горизонта)».
- В дереве исправлено: щелчок глаза у нижних строк больше не отбрасывает список к началу.
